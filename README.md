## Instalação

### Windows (.exe)
* Baixe o arquivo `.exe` e dê um duplo clique para instalar e abrir.

### Linux

**AppImage (Recomendado para qualquer distribuição)**
* Baixe o arquivo `.AppImage`.
* Abra o terminal na pasta onde o arquivo foi baixado.
* Conceda permissão de execução com o comando: 
  `chmod +x "Gestao Local-1.0.0.AppImage"`
* Para iniciar, clique duas vezes no arquivo ou rode pelo terminal com: 
  `./"Gestao Local-1.0.0.AppImage"`

**Debian / Ubuntu (.deb)**
* Baixe o arquivo `.deb`.
* Abra o terminal na pasta onde o arquivo foi baixado e execute: 
  `sudo apt install ./controle-comercio_1.0.0_amd64.deb`
* O atalho ficará disponível no menu de aplicativos como "Gestao Local".

**Arch Linux (.pacman)**
* Baixe o arquivo `.pacman`.
* Abra o terminal na pasta onde o arquivo foi baixado e execute: 
  `sudo pacman -Udd controle-comercio-1.0.0.pacman`
* O atalho ficará disponível no menu de aplicativos como "Gestao Local", ou rode direto no terminal digitando: `controle-comercio`
